# flask-quotes-app

Flask-приложение для хранения любимых цитат: список, добавление,
редактирование, удаление, сортировка и статистика.

## Возможности

- Просмотр списка цитат (отсортированы по году, новые сверху)
- Страница подробностей каждой цитаты
- Добавление новой цитаты с валидацией
- Редактирование существующей цитаты
- Удаление цитаты (POST-запрос)
- Страница статистики
- Единое оформление всех страниц через базовый шаблон

## Редактирование цитат

Редактирование реализовано в функции `edit()` (`app.py`) и шаблоне
`edit.html`.

- На странице подробностей (`/quotes/<id>`) есть кнопка «Редактировать»,
  которая ведёт на `/edit/<id>`.
- Открывается отдельная форма `edit.html`, заполненная текущими значениями
  цитаты (цитата, автор, год).
- После изменения пользователь отправляет **POST**-запрос, данные читаются
  через `request.form`.
- Сервер проверяет корректность данных: цитата, автор и год обязательны,
  год должен быть числом.
- Если данные некорректны — форма возвращается с сообщениями об ошибках
  и ранее введёнными значениями.
- Если всё корректно — объект обновляется, и пользователь перенаправляется
  на страницу объекта через `redirect(url_for("detail", ...))`.

## Реализовано 4 дополнительные функции

### 1) Сортировка записей по году

На главной странице (`/`) все цитаты сортируются по полю `year` 
по убыванию самые новые цитаты показываются первыми. 

### 2) Удаление записи через POST

Маршрут `/delete/<int:quote_id>` принимает только POST. 
Список `quotes` перестраивается, остаются только записи, 
у которых `id` не совпадает с удаляемым. 
После этого — `redirect(url_for("index"))`.

### 3) Добавление стилей

Все стили описаны в одном блоке `<style>` внутри `base.html`. 
Дочерние шаблоны наследуют их через `{% extends %}`. 
Если нужно поменять оформление — правится одно место.

### 4) Страница статистики с количеством цитат

Функция `statistics()` считает `len(quotes)` и передаёт это число в шаблон как переменную `length`. 
В `statistics.html` значение выводится через `{{ length }}`.
